## Sesi 2026-05-17 — Internal Chat & Onboarding Tour

### 1. Fitur Internal Chat (Vendor ↔ Admin)

**Tujuan:** Vendor bisa chat langsung ke admin/super_admin, satu thread per vendor.

**Migration baru:**
- `2026_05_16_142944_add_user_id_to_chat_sessions_table.php` — tambah kolom `user_id`
- `2026_05_16_172903_add_vendor_to_chat_messages_sender_enum.php` — tambah nilai `vendor` ke enum sender
- `2026_05_17_052926_add_type_to_chat_sessions_table.php` — tambah kolom `type` ('public' | 'internal')

**Model:** `app/Models/ChatSession.php`
- Tambah `type` dan `vendor_id` ke `$fillable`

**Controller:** `app/Http/Controllers/ChatController.php`
- `vendorInternalChat()` — GET, buat/ambil 1 thread per vendor (`firstOrCreate` dengan `type=internal`)
- `vendorInternalSend()` — POST, kirim pesan dengan `sender=vendor`
- `vendorInternalPoll()` — GET, polling pesan baru (vendor side)
- `adminInternalIndex()` — GET, list semua thread internal
- `adminInternalDetail()` — GET, detail thread + pesan
- `adminInternalReply()` — POST, balas dengan `sender=admin`
- `adminInternalPoll()` — GET, polling pesan baru (admin side)

**Routes:** `routes/web.php`
```
GET  /dashboard/internal-chat              → chat.internal.vendor
POST /dashboard/internal-chat/send         → chat.internal.vendor.send
GET  /dashboard/internal-chat/poll         → chat.internal.vendor.poll
GET  /dashboard/chat-internal              → chat.internal.admin
GET  /dashboard/chat-internal/{token}      → chat.internal.admin.detail
POST /dashboard/chat-internal/{token}/reply → chat.internal.admin.reply
GET  /dashboard/chat-internal/{token}/poll  → chat.internal.admin.poll
```

**Views baru:**
- `resources/views/dashboard/chat/internal-vendor.blade.php` — UI chat sisi vendor
- `resources/views/dashboard/chat/internal-admin-index.blade.php` — list chat sisi admin
- `resources/views/dashboard/chat/internal-admin-detail.blade.php` — detail chat sisi admin

**Sidebar:** `resources/views/layout/dashboard.blade.php`
- Tambah menu **"Chat ke Admin"** untuk vendor owner
- Tambah menu **"Chat Vendor"** untuk admin/super_admin

### 3. Onboarding Tour (Driver.js v1.3.1)

**Tujuan:** Panduan interaktif untuk pengunjung baru, muncul sekali (localStorage), bisa dipaksa dengan `/?tour=1`.

**Library:** Driver.js v1.3.1 via CDN
```
https://cdn.jsdelivr.net/npm/driver.js@1.3.1/dist/driver.js.iife.js
```

**CSS:** di `@section('extra-head')` dalam `home.blade.php`

**Behaviour:**
- Hanya tampil untuk pengunjung baru (cek `localStorage` key `mw_tour_done_v1`)
- Setelah tour selesai/ditutup → HomeAd modal muncul
- `/?tour=1` untuk force-preview tanpa hapus localStorage

**Step Desktop (6 step):**
1. `#tour-search` — Search bar desktop
2. `#tour-nav-vendor-store` — Wrapper Vendor & Store (highlight keduanya)
3. `#tour-nav-promo` — Link Promo
4. `#tour-nav-real-wedding` — Link Real Wedding
5. `#main-profile-wrapper` — Avatar / Profil & Akun
6. (no element) — Penjelasan fitur Chat

**Step Mobile (4 step):**
1. `#tour-search-mobile` — Search bar mobile
2. `#tour-hamburger` — Tombol hamburger menu
3. `#main-profile-wrapper` — Avatar / Profil & Akun
4. (no element) — Penjelasan fitur Chat

**ID yang ditambahkan ke header.blade.php:**
- `id="tour-search-mobile"` — form search mobile
- `id="tour-hamburger"` — tombol hamburger
- `id="tour-nav-vendor-store"` — wrapper `<span>` Vendor+Store
- `id="tour-nav-promo"` — link Promo
- `id="tour-nav-real-wedding"` — link Real Wedding
- `id="tour-search"` — form search desktop (sudah ada sebelumnya)
- `id="main-profile-wrapper"` — avatar wrapper (sudah ada sebelumnya)

**Integrasi dengan HomeAd:**
- HomeAd auto-timer diblokir selama tour aktif (`window.__tourActive`)
- Setelah tour destroy → `window.openHomeAdModal()` dipanggil dengan delay 400ms
